## Live technical training, wherever you are: A VSLive! benefit for Visual Studio subscribers

- **Blog:** Visual Studio
- **Author:** James Rempt
- **URL:** https://devblogs.microsoft.com/visualstudio/live-technical-training-wherever-you-are-a-vslive-benefit-for-visual-studio-subscribers

### 要約
VSLive! が、.NET、GitHub Copilot、AI コーディングエージェント、Microsoft Foundry などを扱うライブ形式のオンライン技術トレーニングを年間を通じて提供しています。対象となる Visual Studio サブスクライバーは、オンライン研修や対面カンファレンスで最大 900 ドルの割引を受けられます。

### 開発者にとって重要なこと
ドキュメントやチュートリアルだけでなく、講師に質問しながら設計判断や実践的な課題を学べる機会です。チームの .NET アプリのモダナイズや AI エージェント導入、Azure アプリの設計を検討する際のスキル開発に役立ちます。

### アクションプラン
- Visual Studio サブスクライバーは Subscriber Portal で VSLive! の割引対象か確認し、利用条件とイベントごとの割引額を確認する。
- 研修カレンダーで、チームの課題に合う講座と日程を確認する。記事では .NET/Copilot（2026 年 12 月）、AI エージェントによるレガシー .NET のモダナイズ（2027 年 1 月）、Microsoft Foundry（2027 年 2〜3 月）の講座を紹介している。

## PIX 2611.19 - misc bug fixes and improvements

- **Blog:** Pix
- **Author:** Austin Kinross
- **URL:** https://devblogs.microsoft.com/pix/pix-2611-19

### 要約
PIX 2611.19 がリリースされ、前回の 2610.28 の内容に加えて、GPU キャプチャ、シェーダー探索、タイミングキャプチャなどの修正と改善が追加されました。タイルリソースやレイトレーシングの性能改善、大規模な GPU タイミングデータを含むキャプチャの読み込み高速化、各種クラッシュ修正が含まれます。

### 開発者にとって重要なこと
DirectX アプリの GPU キャプチャやプロファイリングで、特定条件下のフレームレート低下、キャプチャ時間・メモリ使用量、クラッシュなどに影響する修正があります。Shader Explorer はドライバーに付属するオフラインコンパイラーを使ったライブプロファイリングにも対応します。

### アクションプラン
- PIX を使う DirectX 開発者は 2611.19 に更新し、利用中の機能に関係する修正をリリースノートで確認する。
- タイルリソース、レイトレーシング、大規模タイミングキャプチャを扱う場合は、更新後に該当するキャプチャとプロファイリングを再実行して改善を確認する。
- PIX のダウンロードページから更新し、問題や提案は DirectX Discord または PIX の Send Feedback から報告する。

- [PIX 2611.19 - misc bug fixes and improvements](https://devblogs.microsoft.com/pix/pix-2611-19)

## Azure DevOps integration with the GitHub Copilot app (public preview)

- **Blog:** DevOps
- **Author:** Dan Hellem
- **URL:** https://devblogs.microsoft.com/devops/azure-devops-integration-with-the-github-copilot-app-public-preview

### 要約
GitHub Copilot アプリで Azure Repos のリポジトリを利用する統合機能がパブリックプレビューとして公開されました。エージェントセッションからブランチ作成、コード変更、コミット、プルリクエスト作成を行い、アプリ内でレビューや複数セッションの管理ができます。Agent Merge を使うと、レビューコメントや CI の問題への対応、準備完了後の自動マージも扱えます。

### 開発者にとって重要なこと
Azure DevOps を利用するチームが、リポジトリを移行せずに Copilot のコーディングエージェントを試せます。一方、機能はプレビュー段階であり、Agent Merge はプルリクエストの自動マージにも関わるため、既存のレビュー・CI・権限運用との適合性を慎重に確認する必要があります。

### アクションプラン
- 試験導入する場合は、Copilot アプリの **Settings > Experimental** で **Azure DevOps integration** を有効にし、まず影響範囲を限定した Azure Repos リポジトリで動作を確認する。
- 必要に応じて **Customize > Installed > Add server** から Azure DevOps Remote MCP Server を追加し、接続先の組織設定を確認する。
- エージェントによるコミットや PR 作成、および Agent Merge の利用前に、リポジトリ権限、レビュー必須条件、CI、マージルールをチームで確認する。プレビュー中は、記事記載の制約や更新を確認しながら利用する。
