## Stop alt-tabbing into the wrong Visual Studio

- **Blog:** Visual Studio
- **Author:** Mads Kristensen
- **URL:** https://devblogs.microsoft.com/visualstudio/stop-alt-tabbing-into-the-wrong-Visual-Studio

### 要約
Visual Studio を複数インスタンスで並行利用するときに、見た目が同じだと誤って別のウィンドウへ切り替えてしまう問題を扱う記事です。タイトルと概要から、ソリューションごとの色分けや識別性を高める機能が紹介されています。

### 開発者にとって重要なこと
Visual Studio を複数ソリューションで使い分ける開発者や、大規模な機能分割をしているチームに関係します。ウィンドウ識別がしやすくなると、誤編集や作業の取り違えを減らせます。

### アクションプラン
- Visual Studio を複数同時起動している場合、ソリューションごとの識別方法が十分か確認する。
- チームで共通の Visual Studio 設定やテーマ運用があるなら、ソリューション単位の色分けが使えるか検討する。
- 複数インスタンス運用時に、誤って別ソリューションを編集しないための手順を見直す。

## Servicing While In Use and ERROR_PACKAGES_IN_USE

- **Blog:** Insidemsix
- **Author:** Howard Kapustein
- **URL:** https://devblogs.microsoft.com/insidemsix/msix-servicing-while-in-use

### 要約
MSIX パッケージを使用中にサービスする際の制約を説明する記事です。概要からは、使用中のパッケージを直接更新しないという前提と、その制約に対する対処方法が整理されています。

### 開発者にとって重要なこと
MSIX を配布・更新するアプリや、端末管理・展開を担当するチームに関係します。更新時に実行中のアプリをどう扱うかは、失敗率やユーザー体験に直結します。

### アクションプラン
- MSIX 更新の運用で、アプリ使用中に失敗する経路がないか確認する。
- `ERROR_PACKAGES_IN_USE` が起きた場合の再試行、延期、終了の方針を決める。
- 配布パイプラインとサポート手順に、使用中パッケージへの対処を反映する。

### リファレンス
- [Servicing While In Use and ERROR_PACKAGES_IN_USE](https://devblogs.microsoft.com/insidemsix/msix-servicing-while-in-use)
