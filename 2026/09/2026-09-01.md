## Servicing While In Use and ERROR_PACKAGES_IN_USE

- **Blog:** Insidemsix
- **Author:** Howard Kapustein
- **URL:** https://devblogs.microsoft.com/insidemsix/msix-servicing-while-in-use

### 要約
MSIX のサービス中にパッケージが使用中だった場合の扱いについて説明する記事です。タイトルと概要から、`ERROR_PACKAGES_IN_USE` に関連する制約と、それを避けるための選択肢が整理されています。

### 開発者にとって重要なこと
MSIX を配布・更新するアプリや、端末管理や展開を担当するチームに関係します。実行中のアプリに対して更新をどう適用するかは、ユーザー体験と運用手順に直結します。

### アクションプラン
- MSIX 更新時にアプリ使用中の状態がどう扱われるかを確認する。
- `ERROR_PACKAGES_IN_USE` が発生する運用経路があるかを見直し、必要なら終了・延期・再試行の方針を決める。
- 配布パイプラインやサポート手順に、使用中パッケージへの対処を反映する。

## Today I will... review GitHub PRs

- **Blog:** Visual Studio
- **Author:** Aaron Powell
- **URL:** https://devblogs.microsoft.com/visualstudio/today-i-will-review-github-prs

### 要約
Visual Studio から GitHub の Pull Request を扱う方法を紹介する記事です。開発チームや OSS プロジェクトでよくある PR レビュー作業を、Visual Studio の GitHub ツールで進める流れが説明されています。

### 開発者にとって重要なこと
Visual Studio を日常的に使う開発者、特に PR レビューを IDE 内で完結させたいチームに関係します。レビューの導線が短くなると、差し戻しや確認作業が減り、共同作業の速度が上がります。

### アクションプラン
- Visual Studio で GitHub PR を確認・レビューする既存手順があるかを見直す。
- チームで IDE 内レビューを標準化できるか試し、コメント・差分確認・承認の流れを揃える。
- Azure DevOps を併用している場合も含め、現行のレビュー手順に合うかを確認する。

### リファレンス
- [Today I will... review GitHub PRs](https://devblogs.microsoft.com/visualstudio/today-i-will-review-github-prs)

## Microspeak: Funded / unfunded

- **Blog:** Oldnewthing
- **Author:** Raymond Chen
- **URL:** https://devblogs.microsoft.com/oldnewthing/20260901-00/?p=112662

### 要約
Microsoft で使われる “funded / unfunded” という用語の意味を解説する記事です。一般的な英語の funding と、社内の Microspeak としての使い方の違いを取り上げています。

### 開発者にとって重要なこと
直接の製品更新ではありませんが、Microsoft 内部の用語や意思決定の背景を理解する助けになります。社内ドキュメントや会話で出てくる言い回しの誤解を減らしたい人に有用です。

### アクションプラン
- Microsoft 系の資料や会話で “funded / unfunded” を見たら、一般的な意味ではなく文脈依存の社内用語として解釈する。
- プロジェクト計画や優先度の議論で、資金・人員・承認のどれを指すのかを明示する。
- 必要なら本文を参照して、社内用語の使い分けをチーム内で共有する。
