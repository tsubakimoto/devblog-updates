## Azure SDK Release (August 2026)

- **Blog:** Azure SDK
- **Author:** Justin Bettencourt
- **URL:** https://devblogs.microsoft.com/azure-sdk/azure-sdk-release-august-2026

### 要約
Azure SDK の 2026 年 8 月版リリースをまとめた月次更新です。今回のまとめでは、49 件の初回 stable / beta リリースを追補しつつ、Document Translation 2.0.0、Storage – Blobs 12.30.0-beta.1、Azure AI Discovery 1.0.0 などの注目更新が紹介されています。  
Document Translation では新しいサービス API や画像内テキスト翻訳、カスタム翻訳モデルの展開が追加され、Storage では新しいサービスバージョン対応や応答形式の拡張、Azure AI Discovery では Python / JavaScript 向けの初の stable リリースが案内されています。

### 開発者にとって重要なこと
Azure SDK を使うアプリやライブラリを扱うチームに直接関係します。月次の SDK 更新は、新機能の取り込みだけでなく、破壊的変更や新しいサービス API への追従判断にも影響します。特に Document Translation や Storage のように利用頻度の高い領域では、依存更新の優先度を見直す材料になります。

### アクションプラン
- Azure SDK の利用状況を確認し、対象サービスごとに更新候補を洗い出す
- ⚠️ Document Translation 2.0.0 や Java / Python の breaking change が自分たちのコードに影響するか確認する
- Storage – Blobs の preview 更新は、使用中のアクセス層・アップロード処理・レスポンス形式に影響がないか検証する
- Azure AI Discovery を使う場合は、Python / JavaScript の stable 移行可否を評価し、Release page で各パッケージの詳細を確認する
