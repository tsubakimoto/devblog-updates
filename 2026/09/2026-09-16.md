## Bringing Correctly Rounded Math to Production with LLVM-libc

- **Blog:** Cppblog
- **Author:** Cody Miller
- **URL:** https://devblogs.microsoft.com/cppblog/bringing-correctly-rounded-math-to-production-with-llvm-libc

### 要約
MSVC の `/Zc:cmath` で、コンパイル時評価と実行時の数学関数に LLVM-libc を使う取り組みについて、LLVM-libc コントリビューターによるゲスト投稿が公開されました。正しく丸められる数学処理を本番投入するまでの背景と実装の話題が中心です。

### 開発者にとって重要なこと
C++ で数値計算や `cmath` を使う開発者、特に MSVC 依存のコードや高精度な丸め挙動に依存するチームに関係します。コンパイラや標準ライブラリの数学実装が変わると、精度・互換性・テスト結果に影響する可能性があります。

### アクションプラン
- C++ プロジェクトで `/Zc:cmath` を使っている場合は、数値テストや境界値ケースの結果を確認する。
- 高精度計算や既存の挙動互換が重要なコードでは、本文を読んで変更点と前提を把握する。
- 必要なら、CI に数学関数の回帰テストを追加して差分を検出する。

### リファレンス
- [Bringing Correctly Rounded Math to Production with LLVM-libc](https://devblogs.microsoft.com/cppblog/bringing-correctly-rounded-math-to-production-with-llvm-libc)

## Important updates: GitHub Copilot support ending for JetBrains 2025.1.x

- **Blog:** Java
- **Author:** Nick Zhu
- **URL:** https://devblogs.microsoft.com/java/github-copilot-support-ending-for-jetbrains-2025-1-x

### 要約
GitHub Copilot プラグインが JetBrains IDE 2025.1.x 系のサポートを終了し、最低サポート版を 2025.2.x に引き上げることが案内されています。新機能と安定性向上を進めるために、より新しい IDE 版へ移行してほしいという内容です。

### 開発者にとって重要なこと
JetBrains 系 IDE で GitHub Copilot を使っている個人やチームに直接影響します。古い IDE を使い続けると、Copilot の更新や修正を受け取れなくなる可能性があります。

### アクションプラン
- ⚠️ JetBrains IDE のバージョンが 2025.2.x 以上か確認する。
- チーム標準 IDE バージョンと Copilot 利用状況を棚卸しする。
- 更新できない環境がある場合は、代替運用や移行計画を立てる。

### リファレンス
- [Important updates: GitHub Copilot support ending for JetBrains 2025.1.x](https://devblogs.microsoft.com/java/github-copilot-support-ending-for-jetbrains-2025-1-x)
