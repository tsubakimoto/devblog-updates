## Announcing .NET 11 Release Candidate 1

## Go 1.27.1-2 Microsoft build now available

- **Blog:** Go
- **Author:** Davis Goodin
- **URL:** https://devblogs.microsoft.com/go/go-1-27-1-2-microsoft-build-now-available

### 要約
Microsoft build の Go 1.27.1-2 が利用可能になりました。OpenSSL 3.3 と、ML-KEM / ML-DSA を実装するプロバイダー利用時の panic 問題を修正しており、Azure Linux 3 との互換性向上が案内されています。  
Go のランタイムや暗号ライブラリに依存する環境では、更新の優先度が高い内容です。

### 開発者にとって重要なこと
Go を使うサービス、特に暗号処理や OpenSSL 連携を含むアプリケーションに関係します。Azure Linux 3 上で動かすワークロードでは、互換性確認の観点でも重要です。

### アクションプラン
- Microsoft build of Go を使っているか確認し、1.27.1-2 への更新を検討する
- ⚠️ OpenSSL 3.3 を使う暗号処理や ML-KEM / ML-DSA 対応プロバイダーの利用箇所を点検する
- Azure Linux 3 で稼働するジョブやコンテナを優先的に検証する
