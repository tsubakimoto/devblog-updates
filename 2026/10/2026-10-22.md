## Are You Getting Everything You Can from Your Visual Studio Subscription?

- **Blog:** Visual Studio
- **Author:** James Rempt
- **URL:** https://devblogs.microsoft.com/visualstudio/what-should-we-blog-about-next

### 要約
Visual Studio サブスクリプションに含まれる Azure クレジット、Cloud Academy や Pluralsight の学習リソース、Syncfusion の開発者向け UI コンポーネントなどの活用例を紹介しています。利用できる特典は契約内容によって異なり、記事では今後取り上げてほしいテーマを募るアンケートも案内しています。

### 開発者にとって重要なこと
対象のサブスクリプションに既に含まれている Azure 利用枠や学習サービス、開発ツールを把握すれば、試作やスキル習得にかかる追加費用や作業を抑えられる可能性があります。特典の利用可否はサブスクリプションによって異なります。

### アクションプラン
- Visual Studio Subscriptions ポータルで、自分やチームの契約に含まれる Azure クレジット、学習サービス、開発者ツールと利用条件を確認する。
- 試したい Azure サービスや UI コンポーネントがあれば、クレジットの上限・対象ワークロードやツールのライセンス条件を確認してから小規模に評価する。
- 今後の記事への要望がある場合は、記事内のアンケートで関心のある技術や開発上の課題を共有する。

### リファレンス
- [Are You Getting Everything You Can from Your Visual Studio Subscription?](https://devblogs.microsoft.com/visualstudio/what-should-we-blog-about-next)

## Develop enterprise-grade apps with SharePoint Embedded

- **Blog:** Microsoft365dev
- **Author:** Steve Pucelik
- **URL:** https://devblogs.microsoft.com/microsoft365dev/develop-enterprise-grade-apps-with-sharepoint-embedded

### 要約
SharePoint Embedded の最新ガイダンスとして、コンテナーや検索可能列の上限、負荷時のスロットリング対策、認証・権限の選択肢が紹介されています。Word、Excel、PowerPoint の共同編集をアプリに組み込む方法や、開発環境からリソースを操作するプレビュー版 MCP サーバー、Visual Studio Code 拡張機能も案内しています。

### 開発者にとって重要なこと
SharePoint Embedded を使うアプリの設計・運用では、テナント単位の上限確認、429/503 応答時の `Retry-After` に従う再試行や並列度制御、最小権限の Graph 権限設計が重要です。記事に記載された上限値は変更される可能性があるため、本番計画時には最新のドキュメントで確認してください。

### アクションプラン
- SharePoint Embedded の新規設計・本番移行前に、最新の上限とコンテナー戦略を確認し、想定するテナント規模で容量を見積もる。
- クライアント側で 429/503 と `Retry-After` を処理し、バックオフ、上限付き再試行、並列度の抑制、アプリ・テナント単位の利用状況監視を実装する。
- 認証方式を見直し、可能な範囲で委任アクセスと `FileStorageContainer.Selected` など対象を絞った権限を評価する。
- Office 共同編集や MCP サーバー、VS Code 拡張機能を検討する場合は、対応機能とプレビュー状況を確認して小規模に試す。

### リファレンス
- [Develop enterprise-grade apps with SharePoint Embedded](https://devblogs.microsoft.com/microsoft365dev/develop-enterprise-grade-apps-with-sharepoint-embedded)

## Embeddings and vector search in Microsoft Agent Framework for Go

- **Blog:** Go
- **Author:** Quim Muntal
- **URL:** https://devblogs.microsoft.com/go/embeddings-and-vector-search-in-agent-framework-for-go

### 要約
Microsoft Agent Framework for Go v0.2.0 に、テキストからベクトルを生成する `embedding` と、ベクトルデータの保存・類似検索を行う `vectordata` API が追加されました。インメモリ、Azure AI Search、Azure Cosmos DB for NoSQL の各コネクターを使い、検索結果をエージェントの RAG コンテキストや会話メモリに活用できます。フレームワークは引き続きパブリックプレビューです。

### 開発者にとって重要なこと
Go アプリケーションで検索や RAG を組み立てる際、複数のストレージに共通する API を使って試作からマネージド検索へ移行できます。一方、埋め込みモデルの次元や文書・クエリ間のモデル整合性、各コネクター固有の検索制約を考慮する必要があります。紹介例の Foundry 埋め込み呼び出しにはモデル利用料金が発生します。

### アクションプラン
- Go 1.26 以降と Agent Framework v0.2.0 の要件を確認し、まずサンプルまたはインメモリ構成で代表的な質問に対する検索結果を評価する。
- 文書とクエリで同じ埋め込みモデルを使い、ベクトル次元を一致させる。モデルを変更する場合は保存済みベクトルの再生成も計画する。
- 本番ストレージを選ぶ際は、Azure AI Search と Cosmos DB のハイブリッド検索機能や、Cosmos DB のパーティションキー制約を確認する。
- Foundry を使う場合は、認証設定と埋め込み利用量・料金を確認し、必要に応じて OpenTelemetry による利用状況の計測を検討する。

### リファレンス
- [Embeddings and vector search in Microsoft Agent Framework for Go](https://devblogs.microsoft.com/go/embeddings-and-vector-search-in-agent-framework-for-go)

## 🚀 React Native Windows v0.85 is here

- **Blog:** React Native
- **Author:** Anukrati Agrawal
- **URL:** https://devblogs.microsoft.com/react-native/react-native-windows-v0-85-is-here

### 要約
React Native Windows 0.85.0 が React Native 0.85.3 を基盤としてリリースされ、旧アーキテクチャが削除されて New Architecture のみとなりました。Visual Studio 2026、.NET 10、Windows App SDK 1.8 が必要で、Modal のタイトルバー・枠線制御、View の outline、TurboModule の先行初期化などが追加されています。入力、タッチ、描画、アクセシビリティ、実行時の安定性に関する修正も含まれます。

### 開発者にとって重要なこと
React Native Windows アプリの 0.85 への更新では、Fabric への移行とビルド環境の更新が必須です。独自のネイティブフォークで削除された内部 WebSocket 実装に依存している場合は、追加の修正が必要になる可能性があります。

### アクションプラン
- ⚠️ 更新前に旧アーキテクチャ利用中のアプリを Fabric に移行し、Visual Studio 2026、.NET 10、Windows App SDK 1.8 のビルド要件を満たす。
- アプリを更新したら、入力、タッチ、スクロール、アクセシビリティ、描画を含む代表的な画面と操作を検証する。
- カスタムネイティブフォークでは、削除された `WinRTWebSocketResource` や `JSBigStringResourceDll` への依存を確認し、必要に応じてリリースノートと移行ガイドを参照する。

### リファレンス
- [🚀 React Native Windows v0.85 is here](https://devblogs.microsoft.com/react-native/react-native-windows-v0-85-is-here)
