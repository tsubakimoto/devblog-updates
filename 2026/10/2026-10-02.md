## Translating an Elasticsearch Search Request to Azure Cosmos DB

- **Blog:** Cosmosdb
- **Author:** Madeline Egan
- **URL:** https://devblogs.microsoft.com/cosmosdb/translating-an-elasticsearch-search-request-to-azure-cosmos-db

### 要約
Elasticsearch の一般的な検索リクエストを、Azure Cosmos DB のクエリパターンで表現する方法を解説するチュートリアルです。Cosmos DB のフルテキスト検索機能へ直接対応付けられる機能がある一方、別クエリやアプリケーション層での処理が必要になる機能もあり、各ステップで最も近いパターンとプロセス上の変更点を示しています。

### 開発者にとって重要なこと
Elasticsearch から Azure Cosmos DB へ検索処理を移行するチームにとって、検索リクエストをそのまま機械的に変換するのではなく、機能ごとの対応可否と実装場所を判断するための資料になります。検索結果の正しさや性能はデータとクエリによって変わるため、移行前後の挙動を実データで比較する必要があります。

### アクションプラン
- Cosmos DB 移行チームは、既存の Elasticsearch リクエストを全文検索、フィルター、ソート、集計などの機能単位に棚卸しし、Cosmos DB の対応するクエリパターンへ分類する。
- 直接対応しない機能は、複数クエリまたはアプリケーション層での処理に分け、結果の正しさ、レイテンシー、RU 消費を代表データで測定する。
- チュートリアルの対応例を出発点にしつつ、利用中の analyzer、検索条件、ページング、パーティション設計への適合性を本文で確認してから段階的に移行する。

### リファレンス
- [Translating an Elasticsearch Search Request to Azure Cosmos DB](https://devblogs.microsoft.com/cosmosdb/translating-an-elasticsearch-search-request-to-azure-cosmos-db)

## Data API builder 2.1.5: JSON and Vector Data Type Support, and More

- **Blog:** Azure SQL
- **Author:** Carlos Robles
- **URL:** https://devblogs.microsoft.com/azure-sql/data-api-builder-2-1-5-json-and-vector-data-type-support-and-more

### 要約
Data API builder (DAB) 2.1.5 が安定版としてリリースされ、SQL の `json` 型と `vector` 型を REST および GraphQL エンドポイントでネイティブに扱えるようになりました。ドキュメントや埋め込みデータを通常の行データと同じエンティティから公開できるようになるほか、本文ではこのリリースの追加変更も紹介されています。

### 開発者にとって重要なこと
Azure SQL の JSON ドキュメントやベクトル埋め込みを API として公開するチームは、個別の変換層を減らし、既存の CRUD API にこれらのデータ型を組み込めます。DAB のバージョン更新に伴うスキーマ、クエリ、クライアント互換性を確認し、REST と GraphQL の両方で実際の入出力を検証することが重要です。

### アクションプラン
- Azure SQL / DAB 管理チームは、DAB を 2.1.5 へ更新できる検証環境を用意し、既存の設定、REST エンドポイント、GraphQL スキーマの回帰テストを実行する。
- SQL の `json` および `vector` 列を公開する設計では、読み書き形式、検索条件、埋め込みの次元数、クライアント SDK の対応を確認し、API 契約を更新する。
- 本番導入前に性能、アクセス制御、入力検証、既存クライアントとの互換性を測定し、本文に記載されたその他の変更もリリースノートとして確認する。

### リファレンス
- [Data API builder 2.1.5: JSON and Vector Data Type Support, and More](https://devblogs.microsoft.com/azure-sql/data-api-builder-2-1-5-json-and-vector-data-type-support-and-more)
