## .NET October 2026 Out-of-Band Security Updates

- **Blog:** .NET
- **Author:** Rahul Bhandari (MSFT)
- **URL:** https://devblogs.microsoft.com/dotnet/dotnet-october-2026-oob-security-updates

### 要約
.NET 8、9、10 向けの更新と .NET 11 RC3 が公開され、Brotli 展開処理のバッファーオーバーフロー（CVE-2026-111497）と、Linux 向け .NET tarball の所有者情報に関する脆弱性（CVE-2026-114148）が修正されました。また、10 月 13 日の更新で修正が不十分だった CVE-2026-70197 と CVE-2026-102870 も再修正されています。.NET Framework は対象外です。

### 開発者にとって重要なこと
Brotli 圧縮データを処理するアプリケーションは、メモリ情報の漏えい、サービス拒否、権限昇格につながる可能性があります。リクエスト展開や HttpClient の自動展開は既定で無効ですが、Brotli API を直接使う場合も含めて影響を確認してください。CVE-2026-114148 は Linux が対象で、.NET 8/9 では ASP.NET Core tarball 利用者にも関係します。

### アクションプラン
- ⚠️ .NET 8 を 8.0.33、.NET 9 を 9.0.22、.NET 10 を 10.0.14 に更新し、.NET 11 RC2 利用者は RC3 へ更新する。
- .NET 8/9/10 のフレームワーク依存アプリは更新済みランタイムを導入して再起動し、自己完結型アプリは更新ランタイムで再ビルド・再公開する。
- コンテナーは更新済み .NET イメージで再ビルド・再デプロイし、Linux のソースビルド利用者は更新済み成果物からパッケージを再ビルドする。
- ASP.NET Core 8/9 の tarball 利用者は、ソースビルドの有無にかかわらず更新済み tarball を適用する。影響対象や各 CVE の詳細はリンク先のセキュリティ勧告を確認する。
