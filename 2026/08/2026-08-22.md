## Today I will... Modernize a .NET application

- **Blog:** Visual Studio
- **Author:** Matt Soucoup
- **URL:** https://devblogs.microsoft.com/visualstudio/today-i-will-modernize-a-net-application

### 要約
Visual Studio に組み込まれた GitHub Copilot の modernizaton tooling を使って、.NET Framework アプリを .NET 10 へ更新し、あわせて Azure への移行も支援する内容です。今回はアップグレード部分に焦点を当てており、詳細は本文参照です。

### 開発者にとって重要なこと
.NET Framework から .NET 10 への移行を検討しているアプリケーション開発チームや、Visual Studio の Copilot ベースの移行支援を使いたい開発者に関係します。既存アプリの近代化と、その周辺の Azure 移行計画にも影響します。

### アクションプラン
- .NET Framework アプリの現状を確認し、.NET 10 へのアップグレード候補を洗い出す。
- Visual Studio の Copilot modernization tooling を使う運用フローがチームに合うか評価する。
- ⚠️ Azure への移行も視野にある場合は、アップグレード手順と移行手順を分けて影響範囲を確認する。
- 詳細な対応内容は本文を参照する。
