## Azure DevOps Remote MCP Server is generally available

- **Blog:** DevOps
- **Author:** Dan Hellem
- **URL:** https://devblogs.microsoft.com/devops/azure-devops-remote-mcp-server-ga

### 要約
Azure DevOps Remote MCP Server の一般提供開始が発表されています。AI アシスタントが Azure DevOps のプロジェクトへ安全かつ文脈付きでアクセスできるようになり、計画・実装・リリースの支援を受けやすくなります。

### 開発者にとって重要なこと
Azure DevOps を使っているチーム、特に AI アシスタント連携や開発フローの自動化を進めたい組織に直接関係します。MCP ベースの接続を使うことで、既存の計画・開発・運用プロセスに AI を組み込みやすくなります。

### アクションプラン
- Azure DevOps を利用しているチームは、Remote MCP Server の導入可否を確認する。
- AI アシスタントからアクセスさせたいプロジェクト、権限、監査要件を整理する。
- 既存の計画・作業・レビューのワークフローにどう組み込むかを検証する。
- ⚠️ 本番データや権限境界に関わるため、セキュリティとガバナンスの確認を先に行う。

### リファレンス
- [Azure DevOps Remote MCP Server is generally available](https://devblogs.microsoft.com/devops/azure-devops-remote-mcp-server-ga)

## Remove Is Not Uninstall

- **Blog:** Insidemsix
- **Author:** Howard Kapustein
- **URL:** https://devblogs.microsoft.com/insidemsix/remove-is-not-uninstall

### 要約
MSIX の「Remove」は、従来の MSI でいうアンインストールと同じではない、という点を解説しています。削除操作に見えても、実際の挙動は単純なアンインストールとは異なることを説明する内容です。

### 開発者にとって重要なこと
MSIX を使ってアプリ配布やパッケージ管理を行う開発者、運用担当者に関係します。削除時の期待値を誤ると、ファイルや設定の扱い、ユーザー体験、サポート対応に影響します。

### アクションプラン
- MSIX を使うアプリの削除・更新フローを、MSI 前提で設計していないか確認する。
- Remove 時に残るもの・消えるものを本文で確認し、サポート手順を更新する。
- 配布や運用ドキュメントに、MSIX の削除挙動を明記する。

### リファレンス
- [Remove Is Not Uninstall](https://devblogs.microsoft.com/insidemsix/remove-is-not-uninstall)
