## Aspire 13.5: Fresh pixels and better workflows

- **Blog:** Aspire
- **Author:** Maddy Montaquila
- **URL:** https://devblogs.microsoft.com/aspire/whats-new-aspire-13-5

### 要約
Aspire 13.5 は、対応言語やデプロイ先、coding agents への拡張を続けてきた流れの中で、見た目と作業フローを改善する更新として案内されています。本文の抜粋からは、ここまでの半年で TypeScript AppHost の完全対応、CLI 機能の追加、ドキュメントワークフローの最適化、Kubernetes と Docker Compose の統合などが含まれていたことが分かります。

### 開発者にとって重要なこと
Aspire を使っている開発者や、マルチ言語・複数デプロイ先のアプリ基盤を扱うチームに関係します。UI/ワークフロー改善は日常の開発体験に直結し、CLI やドキュメント、デプロイ統合の更新は導入済みプロジェクトの運用にも影響します。

### アクションプラン
- Aspire を使っているチームは 13.5 の変更点を確認し、既存の AppHost や CLI ベースの作業に影響がないか整理する。
- TypeScript、Kubernetes、Docker Compose の利用有無に応じて、更新内容を優先的に評価する。
- 詳細は本文を参照し、ワークフロー改善がローカル開発や CI/CD にどう効くかを確認する。

## Announcing AppxManifest IntelliSense Support in the WinApp VS Code Extension

- **Blog:** Ifdef Windows
- **Author:** Chiara Mooney
- **URL:** https://devblogs.microsoft.com/ifdef-windows/appxmanifest-intellisense-support-in-vs-code

### 要約
WinApp VS Code Extension v0.3.0 に、AppxManifest.xml 向けの schema-aware IntelliSense が追加されました。あわせて、ファイルやフォルダーを必要とするコマンドで workspace search が使えるようになり、いくつかの機能改善と信頼性向上も含まれます。

### 開発者にとって重要なこと
Windows アプリを VS Code で開発する .NET、WPF、WinUI、C++、Electron、Rust、Tauri、Flutter の開発者に直接関係します。manifest 編集時の補完と即時エラー検出は、パッケージ定義や検証ミスを減らすのに役立ちます。

### アクションプラン
- WinApp extension を使っているチームは v0.3.0 を導入し、manifest 編集時の挙動を確認する。
- AppxManifest を手作業で編集している場合は、IntelliSense による補完とエラー表示で運用を見直す。
- 詳細は本文を参照し、ワークスペース検索対応が既存コマンドの操作感をどう変えるか確認する。

### リファレンス
- [Announcing AppxManifest IntelliSense Support in the WinApp VS Code Extension](https://devblogs.microsoft.com/ifdef-windows/appxmanifest-intellisense-support-in-vs-code)

- 既存の x86_64 前提のスクリプトや依存関係がないか確認する。
