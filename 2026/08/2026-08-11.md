## The little-known winstart.bat batch file

- **Blog:** Oldnewthing
- **Author:** Raymond Chen
- **URL:** https://devblogs.microsoft.com/oldnewthing/20260811-00/?p=112605

### 要約
Windows 95 時代の `C:\WINDOWS\WINSTART.BAT` が何のためにあり、`C:\AUTOEXEC.BAT` とどう違うのかを解説する記事です。システム起動のどの段階で実行されるかにも触れています。

### 開発者にとって重要なこと
Windows の起動処理やレガシーなバッチの振る舞いを扱う人、古い環境を保守する人に関係します。現代の開発フローへの直接的な影響は小さいですが、互換性調査や OS の挙動理解に役立ちます。

### アクションプラン
- Windows/レガシー環境を保守している場合は、起動時に実行されるスクリプトの流れを確認する。
- `AUTOEXEC.BAT` 前提の手順が残っていないか、古い運用ドキュメントを見直す。
- 詳細は本文参照。

### リファレンス
- [The little-known winstart.bat batch file](https://devblogs.microsoft.com/oldnewthing/20260811-00/?p=112605)

## Intelligent Terminal 0.2 is here with local model support

- **Blog:** Commandline
- **Author:** Hamza Usmani
- **URL:** https://devblogs.microsoft.com/commandline/intelligent-terminal-0-2-is-here-with-local-model-support

### 要約
Intelligent Terminal の 0.2 版が公開され、ローカルモデル対応や `/agent` によるタブごとのエージェント切り替えが追加されました。OpenCode の組み込み、WSL 内でのエージェント実行など、端末内での作業を強化する更新です。

### 開発者にとって重要なこと
コマンドライン中心の開発者、VS Code やターミナルで AI 支援を使う人、WSL 上で作業するチームに関係します。作業場所やモデル選択の自由度が増えるため、既存の端末ワークフローへの影響確認が必要です。

### アクションプラン
- Intelligent Terminal を使っている場合は、0.2 の新機能が既存の作業フローに合うか確認する。
- ローカルモデル利用や WSL 実行が必要なチームは、導入方法と制約を本文で確認する。
- タブごとのエージェント分離が有効か、チームの端末運用に照らして検討する。

### リファレンス
- [Intelligent Terminal 0.2 is here with local model support](https://devblogs.microsoft.com/commandline/intelligent-terminal-0-2-is-here-with-local-model-support)
