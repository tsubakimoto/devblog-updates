## On forcing all derived classes to implement a specific non-virtual method, part 2

- **Blog:** Oldnewthing
- **Author:** Raymond Chen
- **URL:** https://devblogs.microsoft.com/oldnewthing/20260828-00/?p=112654

### 要約
派生クラスに特定の非 virtual メソッドの実装を強制する話題の続編です。前回の考察を踏まえつつ、基底クラス設計で「実装を持たせないことで実装を求める」考え方をさらに掘り下げています。

### 開発者にとって重要なこと
継承ベースの API 設計や抽象基底クラスを扱う開発者に関係します。派生クラスに必須実装をどう表現するかは、拡張性と保守性の両方に影響します。

### アクションプラン
- 抽象基底クラスを使っているチームは、必須メソッドをどう強制しているか見直す。
- 継承階層の設計で、基底クラスに実装を置くべきか、派生クラス側に委ねるべきかを整理する。
- 詳細は本文を参照し、既存 API の制約と合うか確認する。
