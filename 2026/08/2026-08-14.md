## Windows App Development CLI v0.6 - create new WinUI applications, sign packages with Azure, and more

- **Blog:** Ifdef Windows
- **Author:** Zachary Teutsch
- **URL:** https://devblogs.microsoft.com/ifdef-windows/windows-app-development-cli-v0-6-create-new-winui-applications-sign-packages-with-azure-and-more

### 要約
Windows App Development CLI v0.6.0 がリリースされ、WinUI アプリの立ち上げを速くする機能が追加されました。単一コマンドで新規 WinUI プロジェクトを作成できるほか、ターミナル内でコントロールやサンプルを検索したり、手動ビルドなしで .csproj から直接実行したりできます。

### 開発者にとって重要なこと
Windows デスクトップ開発、特に WinUI や Windows App SDK を使うチームに関係します。開発時の初期セットアップ、パッケージ署名、録画共有の流れが変わる可能性があります。

### アクションプラン
- Windows App Development CLI を使っているなら v0.6 の新機能を確認し、テンプレート作成や実行フローを置き換えられるか判断する
- Azure を使ったパッケージ署名や sparse-package 運用がある場合は、既存パイプラインへの影響を確認する
- チームで WinUI 開発をしているなら、導入可否と標準手順の更新要否を検討する

### リファレンス
- [Windows App Development CLI v0.6 - create new WinUI applications, sign packages with Azure, and more](https://devblogs.microsoft.com/ifdef-windows/windows-app-development-cli-v0-6-create-new-winui-applications-sign-packages-with-azure-and-more)

## Forcing an ARM64X executable to run as a specific architecture

- **Blog:** Oldnewthing
- **Author:** Raymond Chen
- **URL:** https://devblogs.microsoft.com/oldnewthing/20260814-00/?p=112613

### 要約
ARM64X 実行ファイルを特定のアーキテクチャとして動かす方法を扱っています。DLL と違って、実行時にどのバイナリ部分が選ばれるかを制御する話題で、ARM64 系 Windows の実行挙動に関する解説です。

### 開発者にとって重要なこと
ARM64/ARM64X を対象にした Windows アプリやツールを扱う開発者に関係します。互換性確認、起動対象の検証、デバッグ時のアーキテクチャ理解に役立ちます。

### アクションプラン
- ARM64X バイナリを配布している場合は、対象アーキテクチャごとの起動挙動を確認する
- 署名や配布の仕組みで ARM64/ARM64X を扱うなら、本文の解説を参照して検証方針を見直す
- ARM64 Windows の不具合調査や性能確認をしているチームは、デバッグ知識として共有する

### リファレンス
- [Forcing an ARM64X executable to run as a specific architecture](https://devblogs.microsoft.com/oldnewthing/20260814-00/?p=112613)

## Git-APE SaaS Factory

- **Blog:** All Things Azure
- **Author:** davidwright
- **URL:** https://devblogs.microsoft.com/all-things-azure/git-ape-saas-factory

### 要約
Azure 上で SaaS を構築する ISV 向けに、Git-APE を使った Agentic Platform Engineering の考え方を紹介しています。PoC を本番運用できる安全でスケーラブルなサービスへ移行するための整理が主題です。

### 開発者にとって重要なこと
Azure 上で SaaS を運用するチーム、特に ISV やプラットフォームエンジニアリング担当に関係します。開発から商用運用への橋渡しや、自動化の設計見直しに役立ちます。

### アクションプラン
- Azure で SaaS を開発しているなら、Git-APE の考え方が現在の開発・運用フローに合うか確認する
- セキュアな商用化や運用自動化の課題がある場合は、本文の推奨事項を取り込む
- チームのプラットフォーム標準やテンプレートに反映できる点を洗い出す
