## Java OpenJDK July 2026 Patch & Security Update

- **Blog:** Java
- **Author:** Josh Martin-Jaffe
- **URL:** https://devblogs.microsoft.com/java/java-openjdk-july-2026-patch-security-update

### 要約
Microsoft Build of OpenJDK の 2026 年 7 月版のパッチ・セキュリティ更新を案内しています。OpenJDK 25 / 21 / 17 / 11 向けの修正と Windows/ARM64 関連の最適化・制限変更が含まれ、リリースノートとバイナリの入手先も案内されています。

### 開発者にとって重要なこと
Microsoft Build of OpenJDK を本番や CI で使っているチームに関係します。特にセキュリティ修正を含むため、利用中の JDK バージョンが更新対象か、Windows/ARM64 やコンテナー利用時の影響がないかを確認する必要があります。

### アクションプラン
- 利用中の OpenJDK バージョンが 25 / 21 / 17 / 11 のどれに当たるかを確認する。
- リリースノートを確認し、既存アプリや CI での互換性検証を行う。
- ⚠️ セキュリティ更新を優先し、Microsoft Build of OpenJDK のバイナリまたは関連コンテナーを計画的に更新する。
