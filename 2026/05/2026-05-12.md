## Foundry Local 1.1: Live Transcription, Embeddings, and Responses API

- **Blog:** Foundry
- **URL:** https://devblogs.microsoft.com/foundry/foundry-local-v1-1

### 要約
Foundry Local 1.1 は、ローカル実行の AI 基盤を大きく拡張するリリースです。まず、マイク入力をそのまま受けてリアルタイム文字起こしを行う Live Transcription API が追加されました。これにより、字幕、音声 UI、会議記録のような低遅延シナリオをクラウドなしで実装できます。さらに、テキスト埋め込み API が加わり、ローカルの semantic search、RAG、クラスタリング、類似検索に使えるようになりました。Responses API も対応し、tool calling や画像入力を含む structured なエージェント実行をオンデバイスで扱えます。あわせて、WebGPU プラグインの分離、JavaScript パッケージの軽量化、.NET 互換性の拡張も案内されています。

### 開発者にとって重要なこと
ローカル AI、オフライン対応、低遅延推論を扱うアプリに直接関係します。特に、音声入力、埋め込み検索、画像理解を同じローカル基盤でまとめたいチームには重要です。SDK の依存関係や実行環境の制約も変わるため、配布サイズやランタイム互換性を見直す必要があります。

### アクションプラン
- Foundry Local を使っているなら、1.1 系 SDK と対応モデルへの更新可否を確認する。
- 音声文字起こし、埋め込み検索、Responses API のどれを採用するかを用途ごとに切り分ける。
- ⚠️ JavaScript の配布サイズや .NET のターゲット互換性、WebGPU プラグイン分離の影響を本文で確認する。

### リファレンス
- [Foundry Local 1.1: Live Transcription, Embeddings, and Responses API](https://devblogs.microsoft.com/foundry/foundry-local-v1-1)

## Introducing dotnet new WinUI templates

- **Blog:** Ifdef Windows
- **URL:** https://devblogs.microsoft.com/ifdef-windows/introducing-dotnet-new-templates-for-winui

### 要約
WinUI 向けの project/item テンプレートが `dotnet new` から使えるようになりました。Visual Studio を開かなくても、新規アプリの作成や実行を CLI で進められます。テンプレートは preview 提供で、コミュニティのフィードバックを元に作られています。Blank、NavigationView、TabView、MVVM などの開始点が用意され、既存アプリに page や dialog などの item テンプレートも追加できます。`dotnet run` で packaged WinUI アプリを直接起動できる点も含め、初期構築の手間を減らす更新です。

### 開発者にとって重要なこと
WinUI 開発を Visual Studio 依存から少し外し、CLI ベースの自動化やスクリプト化をしやすくします。VS Code や他のエディタで開発しているチームにも使いやすい変更です。プロジェクトの雛形を標準化したい場合にも役立ちます。

### アクションプラン
- WinUI の新規作成フローがあるなら、preview テンプレートを試して既存手順と比較する。
- CI や開発スクリプトで `dotnet new winui*` と `dotnet run` を使えるか確認する。
- ⚠️ preview 版なので、Visual Studio 連携やテンプレート仕様の変更可能性を前提に評価する。

### リファレンス
- [Introducing dotnet new WinUI templates](https://devblogs.microsoft.com/ifdef-windows/introducing-dotnet-new-templates-for-winui)

## What's new in Microsoft Foundry | April 2026

- **Blog:** Foundry
- **URL:** https://devblogs.microsoft.com/foundry/whats-new-in-microsoft-foundry-apr-2026

### 要約
Microsoft Foundry の 2026 年 4 月分の更新まとめです。Foundry Local は GA となり、Windows、macOS Apple Silicon、Linux x64 でオンデバイス推論を本番利用しやすくなりました。GPT-5.5 が Foundry に追加されましたが、既定の利用枠は Tier 5/6 に限られるため、下位ティアではクォータ申請が必要です。Agent Framework の tracing、hosted-agent tracing、CodeAct with Hyperlight、continuous evaluation の custom evaluators、Agent Monitoring Dashboard など、エージェント運用向けの可観測性と評価機能が広がっています。さらに、Python / JavaScript / .NET / Java の SDK 更新もまとまっており、月次で追うべき変更点が多い回です。

### 開発者にとって重要なこと
Foundry 上でエージェントやモデル運用をしているチームに広く関係します。新しいモデルの利用条件、トレース、評価、監視、SDK の追従をまとめて確認する必要があります。Build セッション情報もあるため、今後の実装方針を固める材料にもなります。

### アクションプラン
- GPT-5.5 を使う予定があるなら、サブスクリプションの tier と region、クォータを先に確認する。
- Agent Framework / hosted agents を使うなら、tracing と monitoring を有効化する前提で運用設計を見直す。
- SDK の更新点を確認し、Python / JS / .NET / Java のいずれかで pinned version を更新するか判断する。

### リファレンス
- [What's new in Microsoft Foundry | April 2026](https://devblogs.microsoft.com/foundry/whats-new-in-microsoft-foundry-apr-2026)
